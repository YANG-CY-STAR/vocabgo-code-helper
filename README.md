# 词达人 Token 工具 · 使用说明

一个纯前端的网页工具，用微信授权换取词达人（VocabGo）的登录 token。
**不上传、不存储、不经过任何第三方服务器**，所有计算都在你的浏览器里完成。

> 仅供交流学习使用，请勿用于违反平台服务条款的行为。

---

## 一、这是什么

词达人学生端只支持微信登录。登录时微信会给一个一次性 `code`，用它可以换到账号的 `token`（32 位十六进制）。

问题是：**词达人的前端会瞬间把 code 用掉**，等你复制链接时它已经失效了。

本工具用一个小技巧解决这个问题：把授权回调指向一个不存在的路径，让页面 404，这样 code 就留在网址里，可以从容复制、再到工具里换成 token。

---

## 二、快速开始

### 准备

- 一部手机（装有微信）
- 能上网即可，无需安装任何软件

### 三步拿到 token

**第 1 步 · 授权**

在**微信里**打开工具页面（扫码或点链接），点「微信授权」，在微信授权页点「允许」。

**第 2 步 · 复制链接**

授权完成后会出现一个 **404 Not Found** 页面——**这是正常的，不要慌**。

点右上角 `…` → **复制链接**。

复制到的内容长这样：

```
https://app.vocabgo.com/student/_cb?code=071Abc...&state=1
```

**第 3 步 · 换 token**

回到工具页，把链接粘进输入框，点「获取 Token」。

成功的话页面会直接显示 token：

```
8ba6214140b55176f96f2a0cd64ec886
```

点「复制」按钮即可拿走。

## 三、注意事项（很重要）

| 事项 | 说明 |
|---|---|
| **code 一次性** | 有效期约 5 分钟，只能用一次，失败要重新授权 |
| **不要重复粘贴** | 粘进页面就会被消费，再粘第二次必然失败 |
| **必须用 https** | 页面用了 WebCrypto，`file://` 或 `http://` 下无法工作 |
| **授权必须在微信里** | 电脑浏览器无法完成微信 OAuth，会提示「请在微信客户端打开链接」 |
| **别在浏览器打开授权链接** | 会立刻把 code 用掉，且无法登录 |

## 四、电脑上怎么用

授权这一步必须在手机微信里，但**换 token 不限环境**。

推荐流程：

```
① 手机微信：打开工具 → 授权 → 404 → 复制链接
② 把链接发到电脑（微信文件传输助手 / QQ / 邮件都行）
③ 电脑浏览器：打开工具页 → 粘贴 → 换 token
```

Windows / macOS 都可以，Chrome、Edge、Firefox 均支持。

## 五、拿到 token 之后

token 是 32 位十六进制字符串，调接口时放在请求头 `UserToken` 里：

```bash
curl -X POST "https://app.vocabgo.com/student/api/Student/Main" \
  -H "Content-Type: application/json" \
  -H "UserToken: 你的token" \
  -d '{"app_type":1,"version":"2.7.0.261109_01","timestamp":1700000000000,"sign":"..."}'
```

注意：所有接口都需要 `sign` 签名，算法是：

```
sign = md5(按键名升序拼接的 k=v&... + "ajfajfamsnfaflfasakljdlalkflak")
```

Python 示例：

```python
import hashlib

SALT = "ajfajfamsnfaflfasakljdlalkflak"

def sign(params):
    s = "&".join(f"{k}={params[k]}" for k in sorted(params) if params[k] not in (None, ""))
    return hashlib.md5((s + SALT).encode()).hexdigest()
```

## 六、常见问题

**Q：报错「微信服务异常!」**
code 已失效或被用过。重新授权一次，注意复制链接后不要粘两次。

**Q：报错「信封字段不全」**
握手参数位置不对。当前版本已修复（握手信息在 `data.handshake` 里）。

**Q：页面改了没生效？**
浏览器缓存。地址后加 `?v=版本号` 强制刷新，例如 `?v=8`。

**Q：token 多久过期？**
实测数小时内有效，但服务端可能随时失效。失效就重新走一次授权。

**Q：404 之后能不能自动跳回来？**
不能。那个 404 页在词达人域名下，没有 JS，我们改不了它；微信又把回调域锁死在它自己的域名上。只能手动复制。

**Q：这东西安全吗？**
页面是纯前端单文件，没有后端、没有外链、没有埋点。你粘贴的链接只在浏览器内存里处理，刷新即消失。可以断网打开源码自行核对。
