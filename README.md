# 词达人 Code 提取工具

一个纯前端的单文件网页，用微信授权拿到词达人（VocabGo）授权链接里的 `code`。

**不上传、不存储、不经过任何第三方服务器**，所有处理都在你的浏览器里完成。

---

## 它能做什么

- 发起微信授权
- 把授权后链接里的 `code` 提取出来
- 一键复制

**它不做的**：不换 token、不调接口、不保存任何数据。

---

## 为什么需要它

词达人学生端只支持微信登录。授权完成后，微信会在跳转链接里带一个一次性的 `code`（有效期约 5 分钟）。

问题是：授权落地页会**立刻**用掉这个 code，等你想复制时它已经失效了。

本工具把授权回调指向一个不存在的路径 `app.vocabgo.com/student/_cb`，该路径返回 404 静态页（没有 JS），所以 code 不会被消费，可以留在地址栏里从容复制。

> 实测：微信只校验回调**域名**，不校验路径，所以这个技巧成立。

---

## 怎么用

**第 1 步 · 授权**

在**微信里**打开页面，点「微信授权」，在授权页点「允许」。

**第 2 步 · 复制链接**

会出现一个 **404 Not Found** 页面——这是正常的。

点右上角 `…` → **复制链接**，应该长这样：

```
https://app.vocabgo.com/student/_cb?code=071AbC...&state=1
```

**第 3 步 · 提取**

回到页面，把链接粘进输入框，点「提取 Code」，复制结果即可。

---

## 注意事项

| 事项 | 说明 |
|---|---|
| **code 一次性** | 有效期约 5 分钟，只能使用一次，失败要重新授权 |
| **不要重复粘贴** | 如果 code 已被使用，再粘第二次就没用了 |
| **授权必须在微信里** | 电脑浏览器无法完成微信 OAuth |
| **页面需 https** | 本地 `file://` 打开时授权跳转会失败 |
