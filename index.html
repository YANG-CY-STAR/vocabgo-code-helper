它能做什么

用微信授权换取词达人（VocabGo）的登录 token。拿到 token 后可以：

  • 查询账号信息、课程、任务列表、进度与得分
  • 调用它的接口（需自行实现签名）
  • 配合浏览器自动化脚本刷学习任务

不能做的事：绕过考试、替考、修改成绩。本工具只做登录凭证转换。

三步拿到 token

  1. 授权：在微信里打开本页，点「微信授权」，点「允许」
  2. 复制：出现 404 页面时，点右上角 … → 复制链接
  3. 换 token：回到本页，粘贴链接，点「获取 Token」

成功后页面直接显示 token，可一键复制。

关键注意事项

事项说明
code 一次性有效期约 5 分钟，只能用一次；失败要重新授权
不要重复粘贴粘进页面就会被消费，再粘第二次必然失败
必须 https页面用了 WebCrypto，http 下无法工作
授权必须在微信里电脑浏览器无法完成微信 OAuth

报错「微信服务异常」
code 已失效或被用过。重新授权一次即可，注意复制链接后不要再粘第二次。

    
报错「信封字段不全」
握手字段位置不对。新版已修复：握手参数在 data.handshake 里，不在顶层。

    
页面被缓存，改了没生效
地址后加 ?v=版本号 强制刷新。

    
token 多久过期？
实测数小时内有效，但服务端随时可能失效。失效就重新走一次授权。

    
能在 Windows 上用吗？
换 token 可以（Chrome/Edge/Firefox 都支持 WebCrypto）；授权必须在手机微信里。

    
为什么 404 后不能自动跳回来？
404 页在别人域名下，没有 JS，我们改不了；微信又把回调域锁死在自己的域名上。只能手动复制。
