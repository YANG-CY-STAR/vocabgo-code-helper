词达人 · 取 code 助手

授权一次，拿到 code，回电脑换 token。全程不经过任何第三方服务器。

1

点击开始授权

会跳转到微信授权页，点「允许」即可。

2

跳转瞬间：开飞行模式 关键

看到页面开始加载词达人首页时，立刻下拉控制中心打开飞行模式。这样页面加载不出来，code 就不会被用掉。

3

复制链接

点右上角 … → 复制链接。此时链接里应该带着 code=。

4

杀掉微信再恢复网络

上滑后台把微信彻底划掉，然后关闭飞行模式。否则页面会重新加载、把 code 用掉。

5

把链接粘到这里

自动帮你把 code 提取出来，复制后发到电脑。

code 只能用一次，有效期约 5 分钟，提取后请尽快发到电脑。

💻

电脑端：一步换 token

在 Mac 终端执行下面这行，把 code 换成 token（token 会存到本地文件）：

ego-browser nodejs vocabgo_fetch_token.js "https://app.vocabgo.com/student/?authorize=2&code=XXXX&state=1#/student/home"

脚本会用 Chromium 打开链接，让词达人 H5 自己完成 V2 加密换 token，然后从 localStorage 读出 CDR_USER_TOKEN。

code 会交给电脑上的本地脚本换成 token
不经过任何第三方服务器 · 不上传、不保存
